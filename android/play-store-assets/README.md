# Curati App y Curative App: materiales de Play Store

English variants use the `-en` suffix and are generated by `generate-assets-en.ps1`.

Este directorio contiene materiales visuales de ejemplo para preparar la ficha de Google Play:

- `curati-app-logo.png`: logo cuadrado para la identidad visual de Curati App.
- `curati-feature-graphic.png`: gráfico destacado de la ficha.
- `curati-phone-01-purchase.png`: ejemplo de la pantalla de compra única.
- `curati-phone-02-frequencies.png`: ejemplo de la experiencia de frecuencias.
- `curati-phone-03-playlist.png`: ejemplo de la automatización y lista de reproducción.

Las tres pantallas verticales son mockups promocionales generados desde la identidad visual existente. Antes de enviar la ficha, reemplázalas por capturas reales del AAB instalado en un dispositivo o emulador. No uses imágenes de ejemplo como evidencia de una función que no esté disponible en la versión publicada.

El logo base procede de la marca existente en `ios/FrecuenciasCurativasApp/FrecuenciasCurativasApp/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`. El script `generate-assets.ps1` permite regenerar los PNG sin editar el código de la app.

English variants:

- `curative-app-logo-en.png`
- `curative-feature-graphic-en.png`
- `curative-phone-01-purchase-en.png`
- `curative-phone-02-frequencies-en.png`

Run `generate-assets-en.ps1` from PowerShell to regenerate the English variants. These are promotional mockups; replace them with real screenshots from the signed build before submitting the final Play Store listing.
